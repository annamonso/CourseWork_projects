## 📚 Course Summaries

### 🧠 **CS489 — Artificial Intelligence I**
- Implemented a **Tic-Tac-Toe agent** using the **Minimax algorithm** with **Alpha-Beta pruning**.  
- Demonstrates search tree construction, game theory decision-making, and pruning efficiency.

---

### 🤖 **CS577 — Deep Learning**
A series of assignments exploring the foundations of deep learning:
- **HW1:** Basics of computational graphs and gradient flow.
- **HW2:** Implementation of custom `max()` and `min()` autograd functions and detailed backpropagation tracing.
- **HW3:** Extending `im2col` for custom patch extraction and implementing a 2-layer RNN to predict top-2 sequence elements.

---

### 🌐 **CS579 — Online Social Network Analysis**
- Focused on graph theory and network dynamics.
- Includes analysis of online social network datasets (e.g., degree distribution, clustering, centrality).

---

### 📊 **CS584 — Machine Learning**
- Covers core ML topics including regression, classification, and ensemble models.
- Assignments progress from linear models to decision trees and ensemble methods.
- Practical experimentation in **Python (NumPy, pandas, scikit-learn)** with data visualization.
